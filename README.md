# Seafood ERP Demo

Prototype giao diện hệ thống chuyển đổi số cho doanh nghiệp chế biến và xuất khẩu hải sản.

## Demo login

- Username: `admin`
- Password: `admin`

## Chức năng demo

- Tổng quan điều hành
- Quản lý nguyên liệu
- Kho hàng
- Theo dõi sản xuất và tỷ lệ thu hồi
- Đơn hàng
- Xếp giấy / phân bổ hàng đi xuất
- Shipment / container
- Công nợ
- Báo cáo
- Modal tạo dữ liệu giả lập

Đây là frontend prototype HTML/CSS/JavaScript, không có backend.
